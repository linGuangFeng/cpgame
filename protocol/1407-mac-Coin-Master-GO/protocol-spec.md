# 1407 — Coin Master GO 协议与状态机

当前游戏由平台接口与 versionconfig.js 共同确认：平台 ID 1407，协议 gid 55，名称 Coin Master GO。

## 捕获闭包

spin-index.jsonl 包含 501 个 ba>0 最小押注付费起点；合并后的 step-index.jsonl 保留 3479 个 HTTP Step 索引。后续连消与免费 Step 均归属于对应 Round，不计为额外付费 Spin。scene 499 开始的 Round 缺两个实时响应，保持为唯一未完成索引项；其响应从未被合成。

History 共检查 502 个 transfer。19 个 log-view 详情明确返回 fsl，4 个详情的 fsn 超过 12，证明免费 Round 与重触发的 History 结构。

## 状态边界

一个 Round 从 ba>0 的付费 Step 开始，包含所有后续 ba=0 的普通连消和免费 Step。ss=0 表示当前 Delivery 尚有连消；Round 终点为 ss=1 且（fsn=0，或 gt=2 且 nfsc=fsn）。

## 结果模型

盘面为 5轴×4行可见格，rskl 每轴另带1个缓冲格，共25项。中奖采用固定1024 Ways，普通倍率序列1→2→3→5，免费倍率序列2→4→6→10。相邻级联按轴移除银牌中奖格，旧缓冲格与未中奖的银/金牌保持材质和顺序下落，仅顶部空位补新符号；黄金中奖格按前端坐标原位转为WILD。

特殊牌不是可省略装饰：`gfl` 在原协议线上标记第2、3、4轴的金牌；协议解码后必须把所有合资格且不在 `gfl` 的坐标显式还原为银牌，并验证银/金构成完整互斥分区，禁止让银牌只存在于缺省 `else`。银牌中奖被消除；中奖金牌不被消除，而是在下一 Step 变为 WILD；未中奖银/金牌均随同轴队列下落并保留材质。679 组原始相邻级联里共有 2429 张合资格补牌，全部为银牌、金牌为0，因此级联补牌固定生成银牌，不能套用起始牌的银/金概率。SC 可以由初始盘面或级联顶部补牌进入；3个 SC 触发12次免费局，每多1个增加2次，免费局内再次满足条件会扩展 `fsn`。501个付费起点没有一张初始 WILD，WILD 只能由上述金牌状态变化产生。

## 本地采样边界

原厂长期权重仍为 UNKNOWN。本地起始牌生成不再使用人为缺省权重，而是采用 501 个已保存付费起点的 12525 个格子实测计数（H1..H8、SC；WILD=0），并在 7310 张合资格起始牌中显式采样银5737/金1573。级联补牌使用上述独立的 2429/2429 银牌源数据规则。该频数只用于复刻中的证据采样，不等同于原厂理论概率或 RTP，也不在运行时读取 captures、fixtures 或 History。

## 禁止推断

当前证据没有原厂服务器理论权重。Redis Key/member/score 是平台下游适配契约，不是原厂协议事实；fixtures 仅为回归 oracle，运行时禁止读取。

## Redis 独立零倍标记（2026-09-14）

使用 ASCII `#` 表示与前后 Spin 无牌面继承的独立单步无奖 Delivery，ASCII `|` 仍分隔 Spin。例：`完整触发盘|#|完整连消链|#`。零倍整局可直接为 `#`；数字 `0` 仍是原金牌掩码字符。

判断必须来自实际牌面：无 Ways 中奖且无免费触发或重触发。连消结束步虽零倍，但承接前步牌面及金银材质，不得替换；金牌转 WILD 的连消链全部保留。新的免费 Spin 重新发牌且倍率按 FREE_RPX 起点初始化，因此其中无触发、单步零倍的 Spin 可替换，但 fsn/nfsc、rpx、rwa/frwa 等派生状态必须重建一致。

共享 GameRuleCore.generateIndependentLoss(freeMode) 在生成器内部最多5次真实候选，失败使用10张已验证默认盘；银/金材质按起始牌规则赋予。MinimalFactCodec.decode 物化一次后，rebuild(facts) 校验并复用该事实，不能每次交付、重试或 History 重新随机物化。Redis 为空仍失败。旧编码兼容，实际消费端先升级解析器，再启用含 # 的新数据。
