# Jungle Party complete-Round generator

`GameRuleCore` is the only formal gid 33 result-generation core. `LoaderMain` independently
verifies and atomically writes one complete Round per Redis list member. Use
`dist/start-loader.cmd --dry-run --no-pause` to verify without connecting to or writing Redis.

The local scenario mix is demo policy. It is not an estimate of original probability or RTP.
